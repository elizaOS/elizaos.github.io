# elizaos/eliza Daily Update (Aug 9, 2026)

## OVERVIEW 
Development on Aug 9, 2026, focused on stabilizing the agent framework through critical bug fixes in core routing, cloud provisioning, and CI/CD pipelines. Key achievements include migrating connector settings to a modular UI, restoring Gmail sending capabilities, and resolving multiple regressions in agent orchestration and message planning.

## KEY TECHNICAL DEVELOPMENTS

**UI and Connector Migration**
*   Migrated Settings to a new connector-based architecture with per-connector detail pages and improved bot/delegate lens support ([#18175](https://github.com/elizaos/eliza/pull/18175)).
*   Fixed app host pairing issues, allowing session recovery to redeem tokens in-process instead of dead-ending ([#18178](https://github.com/elizaos/eliza/pull/18178)).
*   Resolved browser overlay clearance issues to keep page controls from obstructing the chat composer ([#18124](https://github.com/elizaos/eliza/pull/18124)).

**Core Agent and Orchestration Logic**
*   Improved message routing by extending addressing gates to full engagement routing and preventing meta-narration shipping on callback failures ([#18174](https://github.com/elizaos/eliza/pull/18174), [#18177](https://github.com/elizaos/eliza/pull/18177)).
*   Fixed planner loop issues where preserved tool results were lost mid-turn, and prevented bare link shares from incorrectly spawning coding sub-agents ([#18180](https://github.com/elizaos/eliza/pull/18180), [#18106](https://github.com/elizaos/eliza/pull/18106)).
*   Ensured empty knowledge-search results return diagnostic info rather than verbatim chat shipping ([#18207](https://github.com/elizaos/eliza/pull/18207)).

**Cloud and Plugin Enhancements**
*   Re-enabled Gmail as a message-send connector and implemented security fail-safes for header injection ([#18112](https://github.com/elizaos/eliza/pull/18112), [#18121](https://github.com/elizaos/eliza/pull/18121)).
*   Ensured managed agents are correctly marked as `ELIZA_CLOUD_PROVISIONED` and fixed stuck orchestrator task reaping ([#18165](https://github.com/elizaos/eliza/pull/18165), [#18118](https://github.com/elizaos/eliza/pull/18118)).
