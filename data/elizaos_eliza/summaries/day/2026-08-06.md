# elizaos/eliza Daily Update (Aug 6, 2026)

## OVERVIEW 
Development on Aug 6, 2026, focused on stabilizing the `develop` branch through critical CI infrastructure repairs, cloud service reliability, and the promotion of the latest release candidate to `main`. Significant progress was made in resolving fleet routing issues, improving onboarding flows, and refining the voice-interaction stack.

## KEY TECHNICAL DEVELOPMENTS

**CI Infrastructure and Fleet Stability**
*   Resolved critical CI regressions in the certification-hosted fleet routing by aligning the `HETZNER_FLEET_ONLINE` contract with the certification runner dispatch ([#17814](https://github.com/elizaos/eliza/pull/17814), [#17812](https://github.com/elizaos/eliza/pull/17812)).
*   Improved CI reliability by provisioning dedicated browser lanes and ensuring certification bundles are uploaded even on failed runs ([#17854](https://github.com/elizaos/eliza/pull/17854), [#17799](https://github.com/elizaos/eliza/pull/17799)).
*   Promoted `develop` to `main`, deploying critical billing fixes and voice parity updates ([#17865](https://github.com/elizaos/eliza/pull/17865)).

**Cloud and Onboarding Enhancements**
*   Fixed SSO bridge atomicity and fail-closed behavior to improve security ([#17788](https://github.com/elizaos/eliza/pull/17788)).
*   Enabled onboarding for linked connector users who do not yet have an agent assigned ([#17764](https://github.com/elizaos/eliza/pull/17764)).
*   Fixed unreachable account-pool broker routes by correctly mounting them under `/api/internal` ([#17782](https://github.com/elizaos/eliza/pull/17782)).

**Voice and UI Refinements**
*   Aligned voice delivery parity to prevent filler speech during memory searches ([#17810](https://github.com/elizaos/eliza/pull/17810)).
*   Polished homepage branding and onboarding surfaces, including a new 404 page ([#17786](https://github.com/elizaos/eliza/pull/17786)).
*   Fixed desktop view catalog coverage following recent runtime stack updates ([#17864](https://github.com/elizaos/eliza/pull/17864)).
