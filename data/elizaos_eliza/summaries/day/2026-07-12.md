# elizaos/eliza Daily Update (Jul 12, 2026)

## OVERVIEW 
Development on July 12, 2026, focused on stabilizing the framework through critical CI/CD repairs, enhancing agent configuration surfaces, and advancing realtime voice capabilities. Major progress was made in resolving deterministic regressions in the cloud and voice stacks, alongside the introduction of new operator slash commands and improved Discord integration.

## KEY TECHNICAL DEVELOPMENTS

**Model Configuration & Operator Control**
*   Implemented a comprehensive model configuration API (Stage 1-3), allowing operators to set small, large, and coding sub-agent models with per-mode reasoning effort via a new Settings panel and `/model` subcommands. ([#16164](https://github.com/elizaos/eliza/pull/16164), [#16171](https://github.com/elizaos/eliza/pull/16171), [#16175](https://github.com/elizaos/eliza/pull/16175))
*   Added `/accounts` and `/backend` operator slash commands to provide multi-account management parity across connectors. ([#16198](https://github.com/elizaos/eliza/pull/16198))

**Realtime Voice & Cloud Infrastructure**
*   Integrated the Phase-1 realtime voice session slice, including server, browser client, and evidence harness for Deepgram Flux and Cartesia Sonic. ([#16062](https://github.com/elizaos/eliza/pull/16062))
*   Wired the Cartesia Sonic 3.5 adapter into the TTS API for WAV-format requests, significantly improving synthesis speed for codec-less clients. ([#16030](https://github.com/elizaos/eliza/pull/16030))

**Discord & Connector Enhancements**
*   Added `/ask` command and group-DM support for Discord, enabling interaction in contexts where bots cannot read the full message stream. ([#16107](https://github.com/elizaos/eliza/pull/16107))
*   Refined slash command registration to prevent deadlocks and decluttered the command picker by gating operator-only tools. ([#16183](https://github.com/elizaos/eliza/pull/16183), [#16197](https://github.com/elizaos/eliza/pull/16197))
