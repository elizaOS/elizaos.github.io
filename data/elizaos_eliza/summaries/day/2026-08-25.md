# elizaos/eliza Daily Update (Aug 25, 2026)

## OVERVIEW 
Development on Aug 25, 2026, focused on hardening the computer-use framework, refining coding action profiles, and enforcing a canonical design system. Significant effort was directed toward stabilizing voice and media lifecycles, improving test suite consolidation, and ensuring robust handling of UTF-16 surrogate pairs across various plugins.

## KEY TECHNICAL DEVELOPMENTS

### Computer-Use and Coding Tool Enhancements
*   Hardened the Codex-parity computer-use surface with observation-bound sessions, cancellation fencing, and app-scoped macOS accessibility controls ([#28389](https://github.com/elizaos/eliza/pull/28389)).
*   Introduced a typed Pi-default coding action profile exposing specific tools (READ, SHELL, EDIT, WRITE) with worktree opt-in ([#28287](https://github.com/elizaos/eliza/pull/28287)).
*   Added native `grim` screenshot support for Wayland/wlroots hosts to improve capture reliability ([#28444](https://github.com/elizaos/eliza/pull/28444)).
*   Normalized dense file calls and improved coding session durability for follow-up tasks ([#28289](https://github.com/elizaos/eliza/pull/28289), [#28408](https://github.com/elizaos/eliza/pull/28408)).

### UI/UX and Design System Consolidation
*   Enforced a canonical design system across the application, including migration of raw controls and tables ([#28281](https://github.com/elizaos/eliza/pull/28281)).
*   Refactored and cleaned shared UI molecules to improve accessibility and maintainability ([#28397](https://github.com/elizaos/eliza/pull/28397)).
*   Fixed UI test resolution issues by aliasing cloud-sdk browser-contracts ([#27853](https://github.com/elizaos/eliza/pull/27853)).

### Voice, Media, and Orchestration Stability
*   Resolved stalls in voice response streams by routing authenticated phone turns through the conversation coordinator ([#28318](https://github.com/elizaos/eliza/pull/28318), [#28327](https://github.com/elizaos/eliza/pull/28327)).
*   Grounded Personal Shared media actions in production to prevent tool-failure misinterpretations ([#28369](https://github.com/elizaos/eliza/pull/28369), [#28325](https://github.com/elizaos/eliza/pull/28325)).
*   Enhanced orchestrator security by authenticating credential bridge callers per session and rejecting unknown project IDs ([#28439](https://github.com/elizaos/eliza/pull/28439), [#28440](https://github.com/elizaos/eliza/pull/28440)).
