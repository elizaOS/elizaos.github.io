# elizaos/eliza Weekly Report (Aug 30 - 5, 2026)

## 🚀 Highlights
This week, the ElizaOS development cycle focused on hardening cloud infrastructure, optimizing inference admission, and establishing a robust subscription and billing framework. ## 🛠️ Key Developments

### Cloud Infrastructure & Backup Systems
The team prioritized the durability and reliability of the cloud environment, specifically focusing on agent backup and restore workflows.
- **Backup & Restore:** Implemented a durable backup admission authority ([#29662], [#29694]) and bounded claimant/recovery authority ([#29781]) to prevent shard starvation. Sandbox V2 capabilities were enhanced with atomic backup-admission reservations and quarantined restore workflows ([#29929], [#29950]).
- **Deployment Stability:** Successfully promoted certified develop trees to production ([#30145], [#30366]) and introduced SHA-locked placement A/B certification workflows ([#30107]).

### Billing & Subscription Lifecycle
A new financial taxonomy was introduced to manage agent usage and subscription health.
- **Subscription Management:** Implemented a funding policy distinguishing between allowance-eligible and cash-only usage ([#30165]). New logic ensures subscription allowances are reserved before credit utilization ([#30166]), with added reporting for uncollected overages ([#30167]).
- **Account Security:** Hardened account deletion policies to preserve cancellation receipts ([#29651]) and improved authentication handoffs between the CLI and the application ([#30141]).

### Inference & Performance Optimization
- **Admission Latency:** Reduced inference admission latency by removing redundant global rate limiter calls and optimizing per-organization checks ([#30351]).
- **Security:** Enforced unified account-standing checks across generative provider dispatches to ensure fail-closed behavior ([#29984]).

### Framework Robustness & Features
- **Bettina Family Operations:** Launched an MVP featuring owner-private parenting agreements, Google Calendar synchronization, and approval-oriented workflows ([#30138]).
- **Data Integrity:** Standardized string handling across the codebase using `truncateWellFormed` and surrogate-safe truncation to prevent data corruption in vault segments and wallet addresses ([#30217], [#30208]).
- **UI/UX:** Resolved calendar UI regressions ([#30251]) and unified desktop and mobile settings layouts ([#30343]).
