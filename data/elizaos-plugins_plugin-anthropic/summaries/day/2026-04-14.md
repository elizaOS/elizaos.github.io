# elizaos-plugins/plugin-anthropic Daily Update (Apr 14, 2026)

## OVERVIEW 
Development on April 14 focused on expanding authentication capabilities for the Anthropic plugin, including support for OAuth via Claude Max and a new CLI-based auth mode. Additionally, the team successfully resolved a series of release workflow failures by implementing fixes for package publishing and release serialization.

## KEY TECHNICAL DEVELOPMENTS

**Authentication Enhancements**
*   Added OAuth authentication support, allowing LLM calls to be routed through Claude Max subscriptions using credentials from the system keychain or environment variables ([#17](https://github.com/elizaos-plugins/plugin-anthropic/pull/17)).
*   Introduced `ANTHROPIC_AUTH_MODE=claude-cli` to route model calls through the Claude Code CLI headless mode ([#18](https://github.com/elizaos-plugins/plugin-anthropic/pull/18)).

**Release Workflow Stability**
*   Resolved build and publishing issues by ignoring dirty plugin submodules and unblocking release builds for published packages.
*   Implemented serialization for the release workflow to prevent race conditions during git pushes ([#6753](https://github.com/elizaos-plugins/plugin-anthropic/issues/6753), [#6755](https://github.com/elizaos-plugins/plugin-anthropic/issues/6755)).
