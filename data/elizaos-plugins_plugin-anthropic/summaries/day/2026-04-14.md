# elizaos-plugins/plugin-anthropic Daily Update (Apr 14, 2026)

## OVERVIEW 
Development on April 14 focused on expanding authentication capabilities for the Anthropic plugin, introducing support for OAuth via Claude Max and a new CLI-based auth mode. Additionally, the team resolved a series of release workflow failures by implementing fixes for package publishing and serializing release jobs to prevent race conditions.

## KEY TECHNICAL DEVELOPMENTS

**Authentication Enhancements**
*   Implemented OAuth authentication, allowing LLM calls to route through Claude Max subscriptions using credentials from the system keychain or environment variables ([#17](https://github.com/elizaos-plugins/plugin-anthropic/pull/17)).
*   Added `ANTHROPIC_AUTH_MODE=claude-cli` to support routing model calls through the Claude Code CLI in headless mode ([#18](https://github.com/elizaos-plugins/plugin-anthropic/pull/18)).

**Release Workflow Stabilization**
*   Resolved build and publishing issues by ignoring dirty plugin submodules and unblocking release builds for published packages.
*   Serialized release workflows and added retry logic for git pushes to prevent non-fast-forward errors during concurrent release jobs.
